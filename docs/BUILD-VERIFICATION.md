# Проверка TermTalk 0.9.0

2026-10-22. Локальный выпуск; публикация на GitHub не выполнена.
После подготовки повторены сборка и все 15 проверок: успешно.
Затем изменены только документы и удалены из исходников неиспользуемые эксперименты.
Чистая Release-сборка в build/: Windows, MinGW.org GCC 6.3.0, C11,
CMake 4.3.2. Компиляция без предупреждений. CTest **15/15** (11 C и 4 Python).
Doxygen 1.18.0: build/docs/html/index.html без предупреждений; карта — 31 задача,
зависимости корректны. Локальные ссылки Markdown и XML логотипа проверены.

## Воспроизведение

См. README: установить Python 3 перед конфигурацией, выполнить comp.bat,
затем ctest --test-dir build --output-on-failure. Без Python доступны только
11 C-проверок; это не подтверждение полного набора. Запускать в Windows:
console_native создаёт собственную скрытую консоль и дочерний настоящий клиент.
Тесты используют временные файлы и --no-history, не личные журналы пользователя.

## Границы

- MSVC и все сочетания Windows 10/11, терминалов и шрифтов не проверены.
- Производительность LAN и сотни клиентов не измерялись.
- Файлы 32 ГиБ/1 ТиБ физически не передавались: проверены 64-битные поля,
  счётчики, прогресс и граничные метаданные; реальная передача проверялась на малых файлах.
- Долгий WinAPI-запрос к сетевой файловой системе может задержать остановку
  фонового браузера; отмена кооперативная.
- TLS/E2EE и защита локальной истории не реализованы. SHA-256 не аутентифицирует сервер.
- .github/workflows/windows.yml — подготовленная конфигурация, ещё не запускалась
  на GitHub; локальный успех старого MinGW не доказывает успех MSYS2 CI.
- Новая подготовка не меняет прошлые теги v0.2.0–v0.8.0. Старые отчёты
  сохраняются в истории Git; пути удалённых сборок больше не считаются актуальными.
